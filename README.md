##PROJECT NAME: 
Library Management System in C++
##SHORT DESCRIPTION:
A console-based Library Management System built using C++ and OOP concepts. 
It manages books, students, and issue/return operations using file handling.
##FEATURES: 
- Add, search, and manage books
- Add and manage student records
- Issue and return books
- File handling for data storage
- Preloaded with 50 classic books
##HOW TO RUN:
1. Compile the C++ file using any C++ compiler (g++, MinGW, etc.)
2. Run the generated executable file
3. Make sure "books.txt" is in the same folder as the executable
